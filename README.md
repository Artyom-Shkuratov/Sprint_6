##  Учебный проект Яндекс.Практикума. Тема Page Object

###  UI автотесты для проекта «Самокат»

Этот проект содержит автотесты для пользовательского интерфейса сайта аренды самокатов.  

Тесты написаны на **Python** с использованием **Selenium WebDriver**, **pytest**, отчет по тестированию представлен с использованием  **Allure**.
